<objective>
Make `WebAppJob.cleanup()` run its three shutdown steps independently, skip steps that do not apply after a partial startup, and wait for the web-server thread for a bounded time only.

Purpose: today a failure in `app.stop()` skips both `server.stop()` and the thread join, and the join has no time limit, so a web server that will not stop holds the whole app open until Docker kills it (and the final state save is lost). After this plan one failing step never skips the others, every failure is in the log, and shutdown moves on after 5 seconds with a warning.

Output: changes to `src/python/web/web_app_job.py` (`WebAppJob` only) and new tests in `src/python/tests/unittests/test_web/test_web_app_job.py`. The `MyWSGIRefServer` adapter is changed in plan 129-02, not here.
</objective>

```python
import logging
from threading import Thread

import bottle
from paste import httpserver
from paste.translogger import TransLogger

from .web_app import WebApp
from common import overrides, Job, Context

class WebAppJob(Job):
    def __init__(self, context: Context, web_app: WebApp):
        super().__init__(name=self.__class__.__name__, context=context)
        self.web_access_logger = context.web_access_logger
        self.__context = context
        self.__app = web_app
        self.__server = None
        self.__server_thread = None

    def setup(self):
        self.__server = MyWSGIRefServer(self.web_access_logger, host="0.0.0.0",
                                        port=self.__context.config.web.port)
        self.__server_thread = Thread(target=bottle.run,
                                      kwargs={'app': self.__app, 'server': self.__server,
                                              'debug': self.__context.args.debug})
        self.__server_thread.start()

    def cleanup(self):
        self.__app.stop()
        if self.__server is not None:
            self.__server.stop()
        if self.__server_thread is not None:
            self.__server_thread.join()
```
