<objective>
Make the web server adapter (`MyWSGIRefServer`) safe to stop at any point of its startup and unable to hold the process open, then run the phase gate.

Purpose: plan 129-01 bounded the wait on the web-server thread. Two gaps remain that would defeat it. First, if shutdown arrives in the short moment before the server thread has created its server, `stop()` fails today and the server then starts anyway and serves forever, keeping the web port (a restart would then fail to bind). Second, the web server library starts 10 worker threads that Python waits for at exit, so the process still hangs whenever the server was not stopped cleanly, even though the server thread itself is now a background thread. This plan closes both and proves the second with a real child process.

Output: changes to `MyWSGIRefServer` in `src/python/web/web_app_job.py`, new tests in `src/python/tests/unittests/test_web/test_web_app_job.py`, and the filled-in `129-VALIDATION.md`.
</objective>

src/python/web/web_app_job.py, adapter as it stands before this plan (plan 129-01 does not touch it):
```python
class MyWSGIRefServer(bottle.ServerAdapter):
    quiet = True  # disable logging to stdout

    def __init__(self, logger: logging.Logger, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.logger = logger
        self.server = None

    @overrides(bottle.ServerAdapter)
    def run(self, handler):
        self.logger.debug("Starting web server")
        handler = TransLogger(handler, logger=self.logger, setup_console_handler=(not self.quiet))
        self.server = httpserver.serve(handler, host=self.host, port=str(self.port), start_loop=False,
                                       handler=MyWSGIHandler,
                                       **self.options)
        self.server.serve_forever()

    def stop(self):
        self.logger.debug("Stopping web server")
        self.server.server_close()
```

Verified behaviour of the installed paste 3.10.1 (129-RESEARCH.md experiments E1-E7):
- server_close() alone makes serve_forever() return within about 1 s and frees the port immediately.
- socketserver's shutdown() never returns with paste (deadlock). Never call it.
- paste's 10 pool workers are non-daemon unless daemon_threads=True is passed to httpserver.serve; non-daemon workers keep the process alive at exit.
- self.options is empty in this codebase, so daemon_threads=True does not collide with **self.options.
- paste accepts port "0" and binds an ephemeral port; the bound port is server.server_address[1].

Lock convention, src/python/controller/file_operation_manager.py lines 101-104: `self.__processes_lock = threading.Lock()` declared next to the state it guards, with a comment naming the two threads involved.

Patch target for the paste module: `web.web_app_job.httpserver`.

From plan 129-01 (same file): `WebAppJob._SERVER_THREAD_JOIN_TIMEOUT_IN_SECS = 5.0`, `WebAppJob.cleanup()` in three isolated steps, test class `TestWebAppJobCleanup` with 13 tests that must stay green and unmodified.
