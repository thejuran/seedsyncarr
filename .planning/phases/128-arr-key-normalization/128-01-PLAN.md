<feature>
  <name>Shared Sonarr/Radarr API-key normalization rule</name>
  <files>src/python/common/arr_api_key.py, src/python/common/__init__.py, src/python/tests/unittests/test_common/test_arr_api_key.py</files>
  <behavior>
    normalize_arr_api_key(raw): non-str (None, 123, object) -> ""; str -> raw.strip().
    is_valid_arr_api_key(key): True only when key is a str and ARR_API_KEY_CHARS.fullmatch(key) is not None; False otherwise, never raises.
    Cases (raw -> normalized, valid-after-normalize):
      None -> "", False
      123 -> "", False
      "" -> "", False
      "   " -> "", False
      "\t\r\n" -> "", False
      "abcDEF123" -> "abcDEF123", True
      "  abcDEF123\n" -> "abcDEF123", True
      "\tabcDEF123  " -> "abcDEF123", True
      "\u00a0abcDEF123\u00a0" -> "abcDEF123", True   (NBSP padding; str.strip treats NBSP as whitespace; pinned, RESEARCH Pitfall 3)
      "abc def" -> "abc def", False
      "abc\tdef" -> "abc\tdef", False
      "abc\ndef" -> "abc\ndef", False
      "abc\r\ndef" -> "abc\r\ndef", False
      "a\x00b" -> "a\x00b", False
      "clé" -> "clé", False
      "abc\u00a0def" -> "abc\u00a0def", False   (inner NBSP)
      "!~" -> "!~", True      (range boundaries \x21 and \x7e)
      "a\x7fb" -> "a\x7fb", False
    The two NBSP rows use the Python escape \u00a0 (U+00A0, no-break space). In the test source they must be written with that escape, never as a literal no-break space character and never as a plain space, so the rows cannot silently turn into ordinary-space cases (which would still pass and leave NBSP behaviour unpinned).
  </behavior>
  <implementation>A dependency-free module in common/ importing only re and typing, re-exported from the barrel in the existing X as X style.</implementation>
</feature>
