<objective>
Close the parser-differential SSRF bypass (125-REVIEW CR-01) and the related review findings inside the Test Connection guard, test-first, per owner decisions D-11 and D-12.

Purpose: today `_validate_url` checks the host `urllib.parse` sees, while `requests`/`urllib3` connect to a different host when the URL contains a backslash, so any loopback port or `169.254.169.254` is reachable. This plan makes the guard refuse every URL the two parsers could read differently, validates the exact string that is requested, refuses the two cloud-metadata addresses inside allowed ranges, makes malformed hostnames a normal JSON error, and stops depending on interpreter `ipaddress` tables for IPv6 transition forms.
Output: RED commit `test(125-04)` (test file only), GREEN commit `fix(125-04)` (config.py only), 125-04-SUMMARY.md.
