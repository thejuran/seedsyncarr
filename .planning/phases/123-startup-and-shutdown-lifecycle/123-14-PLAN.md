<interfaces>
Harness conventions (123-restart-cycle.sh, 123-09 version):
- `set -u`; `step <name>` prints `STEP <name> <utc>`; `add_fail <reason>` appends to FAIL_REASONS; `count_str "<fixed string>" <file>` counts safely; the EXIT trap writes `CYCLE_<label>=INCOMPLETE:<step>` unless a verdict was written
- `DOCKER="sudo /usr/local/bin/docker"`; container `seedsyncarr-test`; log /volume1/docker/v5test/seedsyncarr/log/seedsyncarr.log
- Step 3 is the only lifecycle action: `$DOCKER restart seedsyncarr-test`
- Recorded-only today: EXITED_SUCCESSFULLY, STOPPED_DURING_SHUTDOWN, ERROR_LINES, RESTART_ELAPSED_S
- The script is copied into the capture dir as `<D>/restart-cycle.sh`; the sampler will be copied as `<D>/proc-sampler.sh` (same dir; restart-cycle finds it as "$D/proc-sampler.sh")

Sample file format (fixed; `<D>/procs-<label>.txt`), one block per sample:
- header line: `S <seq> <utc ISO with ms, from date -u +%FT%T.%3NZ> init=<host pid from docker inspect -f '{{.State.Pid}}' seedsyncarr-test, 0 if not running>`
- one line per container pid: `P <pid> <ppid> <pgid> <sid> <state> <comm>`. Parsed from `/proc/<pid>/stat`: comm is the text between the first `(` and the last `)` with spaces replaced by `_`; state, ppid, pgrp and session are the 1st-4th fields after the last `)`. Pids whose stat cannot be read are skipped.
- Pids come from the default `docker top seedsyncarr-test` output: skip the header line, PID is column 2.
- Sample 1 is taken before the restart and the file `<D>/sampler-<label>.ready` is touched right after it. The loop ends when `<D>/sampler-<label>.stop` exists or SAMPLER_MAX_S (default 120) seconds pass, sleeping SAMPLER_INTERVAL_S (default 0.5) between samples.
- Overridable for local tests only: `SAMPLER_DOCKER` (default `sudo /usr/local/bin/docker`), `PROC_ROOT` (default `/proc`), SAMPLER_MAX_S, SAMPLER_INTERVAL_S.

Verdict definitions (awk over the sample file):
- OLD_INIT = init of sample 1. Old generation = samples whose init equals OLD_INIT. The verdict only reads samples up to the first sample whose init differs.
- OLD_LFTP_PIDS = pids with comm `lftp` in sample 1. OLD_LFTP_CHILD_PIDS = pids in sample 1 whose ppid is in OLD_LFTP_PIDS.
- LAST_OLD = the last old-generation sample. BG lftp = an lftp pid in any old-generation sample that is not in OLD_LFTP_PIDS.
- Reasons, in this order: `lftp_not_reaped` (an OLD_LFTP pid is in LAST_OLD), `lftp_child_survived` (an OLD_LFTP_CHILD pid is in LAST_OLD), `lftp_backgrounded` (a BG lftp pid is in LAST_OLD).
- UNDETERMINED reasons: `no_presample` (no sample 1 or init=0 in it), `no_lftp_before` (OLD_LFTP_PIDS empty), `too_few_old_gen` (fewer than 2 old-generation samples).
- Output `<D>/procs-<label>.env` with PROCS_RESULT, OLD_INIT, OLD_LFTP_PIDS, OLD_LFTP_CHILD_PIDS (pid:comm list), OLD_GEN_SAMPLES, LFTP_STATES_SEEN, LFTP_ZOMBIE_SEEN, LFTP_GONE_UTC (or none), BG_LFTP_SEEN, SAMPLES_TOTAL. Also print the same lines to stdout.
