<orchestrator_amendment date="2026-10-26">
Same rules as 123-06/123-11/123-12:
- sandbox `seedsyncarr-test` only
- production read-only fingerprint only
- never read, print or rotate the sandbox Sonarr key
- Docker on the NAS only via `sudo /usr/local/bin/docker ...`
- evidence committed locally, not pushed
- harness waits allowed; product code gets nothing here
Lessons from the GAP-1 round, binding here:
- (1) On this NAS's remote shell, `A && nohup B &` blocks for B's whole duration. Always write `A; nohup B > log 2>&1 < /dev/null &` and confirm the ssh call returns in under 1 s.
- (2) Never re-issue a restart until state.env and the logs show the previous one did not run. 123-11 accidentally double-restarted I1.
- (3) `umask 077` does not give 0700 under the Synology ACL; run an explicit `chmod 700`.
- (4) Keep every ssh call under about 2 minutes and poll. A 600 s no-progress watchdog kills executors.
- (5) The app log is America/New_York local time (EDT, UTC-4 until 2026-11-01).
</orchestrator_amendment>
