<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Controller thread -> main loop | Startup exceptions cross threads via exc_info; the main loop decides restart vs surface |
| Server -> web UI status | `server.error_msg = str(exc)` is shown to the UI user |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-123-01 | Denial of service | Job.run setup failure leaving a dead controller thread while the app looks up | mitigate | setup() wrapped; exc_info + shutdown_flag set; cleanup runs; propagate_exception surfaces it into RECOV-01 (tests test_setup_exception_propagates, test_setup_failure_thread_runs_cleanup_and_surfaces) |
| T-123-02 | Information disclosure | Raw OSError/RuntimeError text (paths, errno) reaching the web UI via server.error_msg | mitigate | Non-AppError wrapped in ControllerError with a fixed generic message; original only in the server log via logger.exception; test asserts "fork failed" not in str(err) |
| T-123-03 | Repudiation | Cleanup error masking the original startup failure | mitigate | cleanup() guarded; exc_info only set from cleanup when empty (test_setup_error_not_masked_by_cleanup_error) |
| T-123-04 | Denial of service | Non-AppError startup failure exiting the whole container (new behaviour, D-05) | mitigate | ControllerError(AppError) routing keeps it inside the bounded ServiceRestart / server.up=False path |
</threat_model>
