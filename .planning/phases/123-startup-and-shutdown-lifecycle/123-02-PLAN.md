- `stop()`: `if not self.__started: return; self.__started = False; self._terminate_and_join_all()`

- Logger: `self.logger = context.logger.getChild("ScanManager")`
- ScannerProcess is an AppProcess (multiprocessing.Process). AppProcess.terminate() is bounded: it sets a flag, waits up to 1000 ms, then sends SIGTERM, and children run SIGTERM as SIG_DFL. So join() after terminate() returns once the child exits. Calling terminate() on a never-started Process raises (its `_popen` is None), which is why only started processes may be cleaned up.
src/python/controller/controller.py `Controller.exit()` has the in-repo pattern to mirror (do not edit controller.py here): `for component, stop in (("lftp", ...), ...): try: stop() except Exception: self.logger.exception("Error stopping {} during controller exit".format(component))`.
src/python/controller/file_operation_manager.py `stop()` (today): snapshots `self.__active_command_processes` under `self.__processes_lock`. For each wrapper with a non-None `wrapper.reservation` it calls `wrapper.reservation.release()`, then logs debug "Released root reservation for '{}' on stop" with `sanitize_log_value(wrapper.reservation.name)`. Then `if not self.__started: return`, then extract_process terminate(), join(), `__started = False`.
