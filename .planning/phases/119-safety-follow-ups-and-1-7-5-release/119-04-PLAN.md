## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SeedSyncarr → Sonarr/Radarr HTTP | Outbound authenticated calls to operator-configured LAN URLs; responses are untrusted JSON |
| Arr response → logs/model | Torrent names in `outputPath` flow into log lines and later into hold reasons |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-119-11 | Information disclosure | API key in logs/exceptions | mitigate | Header auth only; log status code / exception class name; no URL, headers or body; test asserts no key in any log call |
| T-119-12 | Tampering (log injection, CWE-117) | Torrent names from arr JSON | mitigate | `sanitize_log_value` on every logged name; outputPath only logged as sanitized basename at DEBUG |
| T-119-13 | Denial of service | Oversized/slow/malformed arr response stalls the controller thread | mitigate | `timeout=(3.05, 10)`, `MAX_RESPONSE_BYTES` cap, type validation at the boundary, capped backoff, one fetch per arr per cycle |
| T-119-14 | Spoofing | Wrong release matched (title collision) | mitigate | Match on `basename(outputPath)` exact + group by `downloadId`; `title` never used; >1 group → ambiguous hold |
| T-119-15 | Elevation | Treating absence/empty queue as complete | mitigate | Zero candidates → `no_queue_entry` or `<arr>_unavailable`, never proven (D-04/D-05) |
| T-119-SC | Tampering | npm/pip/cargo installs | accept | No package installs (requests already a runtime dependency) |
