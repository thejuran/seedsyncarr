<objective>
Close the gap codex found in B2: a transfer that was submitted to lftp but never observed in a successful status (parse failure immediately after the QUEUE) is DEFAULT in the model, so with status unavailable AutoQueue can re-submit it after the cooldown and a successful local scan showing a preallocated size can mark it DOWNLOADED (committing it, firing auto-extract, exposing it to delete). Protect such transfers until the first successful status reconciliation (XFER-02, D-01). Codex pass 2 showed the model-level protection alone is not enough: `Controller.process()` runs `__process_commands()` before `__update_model()`, and every command in the batch is handled against the previous cycle's frozen ModelFile, so a QUEUE followed by EXTRACT / DELETE_LOCAL / DELETE_REMOTE for the same DEFAULT file passes the existing state guards after lftp has already accepted the transfer. The same set therefore also guards the command handlers at execution time. Codex pass 3 showed one more leak: `Lftp.kill` polls `Lftp.status()` directly, bypassing `LftpManager.status()` and its set-clearing, so after submitted -> unavailable -> successful STOP the name stayed tracked and the `_handle_queue` guard would silently swallow the user's restart; `LftpManager.kill` therefore reconciles the killed name out of the set once `Lftp.kill` returns.

Purpose: the phase goal is "never make a re-queue, auto-queue, or delete decision from a transfer state it did not actually observe". Returning None (Plan 05) protects transfers that were observed at least once; this plan protects the ones that were never observed. Placement is Claude's discretion: the set lives in LftpManager (the one object that knows a queue command was actually sent and whether the next status was available), is surfaced to the model as the existing QUEUED state, and is purely in-process (persistence is out of scope per spec).

Output: four edited production files (lftp_manager.py, model_builder.py, model_pipeline.py, command_processor.py), three extended unit test files; commit `fix(117-08): protect submitted-but-unobserved transfers until first successful status (B2)`.
</objective>
