Purpose: downstream code already treats `None` as "keep last-known state" (ModelPipeline, ModelBuilder, Controller active list, AutoQueue, auto-delete all verified in RESEARCH §B2 Consumer Trace). Returning `None` instead of `[]` is what keeps a DOWNLOADING file protected through a transient parse error (D-01).
